# 个人物品库存台账 功能介绍

> 一款完全离线、纯本地存储的个人实物库存管理微信小程序。
> 登记实物库存、拍照存档、增减库存、实时计算到期状态，防止重复采购、遗忘存货。

---

## 一、产品定位

| 项目     | 说明                                               |
| -------- | -------------------------------------------------- |
| 产品名称 | 个人物品库存台账                                   |
| 目标用户 | 个人自用（宿舍 / 家用）                            |
| 使用场景 | 管理食品、药品、电子配件、日用品耗材等实物         |
| 技术栈   | UniApp（Vue3），编译为微信小程序                   |
| 部署方式 | 无后端、无云函数、无服务器，数据全部保存在微信本地 |
| 运行形态 | 完全离线可用，不依赖网络                           |

**解决的核心问题**：家里东西多、容易重复采购、食品药品放过期。用手机随手登记一件物品（数量、位置、保质期、照片），打开小程序就能看到哪些东西快过期了、放在哪里、还有多少。

---

## 二、核心功能总览

小程序共 5 个页面，覆盖「登记 → 查看 → 到店管理 → 备份」的完整闭环：

```
首页（列表 / 搜索 / 筛选 / 排序）
   ├── ＋ 新增物品 → 表单页 → 详情页
   ├── 物品卡片   → 详情页（数量＋/−、编辑、删除）
   └── ⚙ 设置     → 分类管理 / 预警阈值 / CSV 导入导出 / 清空 / 关于
```

| 页面            | 一句话功能                                               |
| --------------- | -------------------------------------------------------- |
| 首页            | 一眼看清全部库存：哪些已过期、哪些快到期、放在哪、剩多少 |
| 新增 / 编辑表单 | 登记物品信息并拍照存档                                   |
| 物品详情        | 查看完整信息，快速增减库存                               |
| 设置            | 分类管理、到期阈值、CSV 备份 / 恢复                      |
| 分类管理        | 维护自定义分类，统计各分类物品数量                       |

## 三、各功能模块详细说明

### 3.1 首页：物品列表

**搜索**：按物品名称模糊搜索，边输入边实时过滤。

**筛选**（三个维度可叠加）：

- 到期状态：全部 / 已过期（红）/ 即将到期（黄），角标直接显示两类各有几件
- 分类：全部或指定分类（含「未分类」）
- 存放位置：从现有物品中自动汇总可选位置

**排序**（三种）：

- **剩余到期天数升序（默认）**：快过期的自动排最前，未填保质期的排最后
- 录入时间倒序：最近登记的排最前
- 物品名称升序

**物品卡片**：缩略图（无图显示分类色首字占位图）、名称、分类 · 位置、数量、到期状态标签。

| 标签             | 样式     | 含义                              |
| ---------------- | -------- | --------------------------------- |
| `【已过期】`   | 红底白字 | 保质期已过                        |
| `【即将到期】` | 黄底黑字 | 剩余天数在预警阈值内（默认 7 天） |
| 无标签           | —       | 正常，或未填写保质期              |

**其他**：右下角悬浮「＋」一键新增；空状态引导文案；列表底部常驻提示数据保存位置与备份方法。

### 3.2 新增 / 编辑物品（同一表单页）

| 字段           | 必填 | 说明                                                               |
| -------------- | ---- | ------------------------------------------------------------------ |
| 物品名称       | ✅   | 最长 60 字，如「维生素 C 片」                                      |
| 分类           | 选填 | 下拉选择，底部可直接「＋ 新增分类」，即时生效                      |
| 存放位置       | 选填 | 自定义文本，如「书桌抽屉」「冰箱上层」                             |
| 数量           | ✅   | 数字输入，**支持小数**（如 0.5），最多两位小数               |
| 购买日期       | 选填 | 日期选择器，选择范围到当天为止                                     |
| 保质期截止日期 | 选填 | 日期选择器，可随时清空；**留空代表无保质期，不参与到期判断** |
| 备注           | 选填 | 多行文本，最多 500 字                                              |
| 物品图片       | 选填 | 拍照 / 相册选 1 张，保存在小程序沙盒，替换或删除时自动清理旧文件   |

**校验与交互**：必填项缺失、数量格式错误、保质期早于购买日期时，表单下方显示红色错误提示；「取消」时若有未保存修改会二次确认，防止误操作丢数据。

### 3.3 物品详情

- **图片**：点击放大预览（`previewImage`）
- **到期提示**：根据当前日期实时计算并显示文字——
  - 「距离到期还有 N 天」（正常）
  - 「今天到期」（到期当天）
  - 「已过期 N 天」（过期后）
  - 未填保质期则不显示
- **数量增减**：＋ / − 按钮一步修改库存并即时保存，数量不小于 0，支持小数
- **编辑**：跳转到表单页回填全部信息
- **删除**：二次确认弹窗；确认后同时删除沙盒内的图片文件
- **完整信息**：分类、位置、数量、购买日期、保质期、备注、录入 / 最后修改时间

### 3.4 设置

| 功能             | 说明                                                                                                    |
| ---------------- | ------------------------------------------------------------------------------------------------------- |
| 数据概览         | 物品种类、分类数、已过期、即将到期                                                                      |
| 分类管理（入口） | 跳转分类管理页                                                                                          |
| 到期预警阈值     | 设置提前几天标记「即将到期」，默认 7 天，范围 0~3650，提供 3 / 7 / 14 / 30 快捷预设                     |
| 导出全部库存     | 生成 CSV 备份文件写入小程序沙盒，可「发送到聊天」转存到手机                                             |
| 导入物品（CSV）  | 从微信聊天记录选择 CSV 文件，支持**追加导入**或**覆盖导入**，逐行校验、错误行跳过并提示原因 |
| 清空全部数据     | **两层确认弹窗**；删除全部物品、分类及沙盒图片                                                    |
| 关于             | 版本号、存储占用、数据安全提示                                                                          |

### 3.5 分类管理

- 查看全部分类及**每个分类下的物品件数**
- 新增自定义分类（最长 12 字，重名拦截）
- 删除分类（二次确认；删除后该类物品保留原分类文字，不影响已有数据）
- 一键「恢复默认分类」（食品、药品、电子配件、日用品耗材、清洁用品、其他）

## 四、业务规则：到期状态计算

到期标记是**进入页面时由前端 JS 实时计算**的，不写入数据库、不依赖任何后台任务。

```
剩余天数 = 保质期截止日期 − 当前日期（按自然日）
  >  预警阈值        → 正常，无标记
  0 < 剩余天数 ≤ 阈值 → 【即将到期】（黄）
  剩余天数 ≤ 0       → 【已过期】（红）
  保质期为空 / 非法   → 不参与判断，无标记
```

> 即使今天不打开小程序，下次打开时也会按当天日期重新计算，不会出现"过期了却不提醒"的漏报。

## 五、数据模型与存储

所有业务数据以 JSON 保存在微信小程序 **storage** 中，图片保存在**小程序沙盒文件目录**：

| 存储    | key / 目录            | 内容                                                             |
| ------- | --------------------- | ---------------------------------------------------------------- |
| storage | `items`             | 物品数组（名称、分类、位置、数量、日期、备注、图片路径、时间戳） |
| storage | `categories`        | 分类数组                                                         |
| storage | `config`            | 全局配置（到期预警阈值）                                         |
| 沙盒    | `inventory_images/` | 物品拍照图片                                                     |
| 沙盒    | `backup/`           | 导出的 CSV 备份文件                                              |

**物品字段**：`id / name / category / location / count / buy_date / expire_date / remark / img_path / create_time / update_time`

## 六、数据备份与恢复（CSV）

导出文件使用固定表头，兼容 Excel（自动带 UTF-8 BOM，中文不乱码）：

```
name,category,location,count,buy_date,expire_date,remark,img_path
```

- **导出**：将全部库存导出为 CSV，写入小程序沙盒；因沙盒文件无法直接保存到手机，提供「发送到聊天」（转发给文件传输助手）后另存，实现真正意义上的备份
- **导入**：从微信聊天记录选择 CSV 文件，支持追加 / 覆盖两种模式；可智能识别逗号、分号、制表符分隔，兼容引号包裹与字段内换行，未知列 / 格式错误的行会被跳过并列出原因，不会污染现有数据
- **图片说明**：图片仅存于本机沙盒，CSV 只导入导出文字信息，跨设备需重新拍照（V1 设计如此）

## 七、安全与合规

- **纯本地**：无服务器、无后端、无云函数，任何数据都不上传
- **权限最小化**：仅申请相机、相册（拍照存档）与聊天文件选择（导入 CSV），不申请定位、通讯录、麦克风等其他权限
- **无打扰**：无订阅消息、无推送通知、无后台定时任务
- **高危操作防护**：删除物品、删除分类、删除备份文件、清空数据均有二次确认弹窗

**数据丢失提示**（界面内多处置顶显示）：删除小程序、清理微信缓存或更换手机都会丢失全部本地数据，请定期导出 CSV 备份。

---

## 八、技术亮点

- **编译产物轻量**：主包约 140 KB（含全部页面与逻辑），远低于微信 2 MB 主包上限
- **数据一致性**：内存响应式状态 + storage 持久化双向同步，进入页面即从本地重新装载，编辑返回后列表自动刷新
- **实时计算不落库**：到期状态、剩余天数全部为渲染时计算，无脏数据、无过期缓存
- **图片生命周期管理**：拍照入沙盒、删除物品 / 替换图片 / 清空数据时自动清理对应文件，不残留孤儿文件
- **CSV 引擎健壮**：自研解析器支持 BOM、引号转义、字段内换行、多分隔符、按表头名定位列，导入导出自洽（导出的文件可完整导回）
- **跨端预览**：同一套代码可编译 H5 在浏览器快速预览 UI（数据走 localStorage，仅供调试）
